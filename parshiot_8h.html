Get the Torah reading for a given Shabbat date.

Parameters
[in]datemust be a Saturday (getDayOfWeek == 7 in Hebrew convention, or abs_day % 7 == 0); pass as any calendar type.
[in]in_israel1 for Eretz Israel schedule, 0 for Diaspora.
[out]readingpopulated with the reading (p1==HC_PARSHA_NONE → Yom Tov).
Returns
0 on success, -1 if date is not a Saturday or is out of range.
