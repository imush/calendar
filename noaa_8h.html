Detailed Description

Solar position calculations using the NOAA algorithm.

Provides Julian Day conversion and sunrise/sunset event computation. Times are minutes from local midnight (local standard time). HC_ZMAN_UNAVAILABLE is returned for polar conditions.

Time (minutes from local midnight) when the sun crosses elev_deg.

An observer above sea level sees a depressed horizon; the depression (radians) is subtracted from elev_deg so that all event times are shifted accordingly (sunrise earlier, sunset later). Pass observer_elev_m = 0 to disable the correction.
